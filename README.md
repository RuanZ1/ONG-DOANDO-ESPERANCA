# ONG Doando Esperança — Plataforma Web Front-End

Este repositório contém o código-fonte completo e validado da plataforma web da **ONG Doando Esperança**, desenvolvido para o projeto prático do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 🌐 Demonstração Ao Vivo
Aceda ao site interativo publicado no GitHub Pages:
👉 **[https://RuanZ1.github.io/ONG-DOANDO-ESPERANCA](https://RuanZ1.github.io/ONG-DOANDO-ESPERANCA)**

---

## 🛠 Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação acessível de formulários, seções e navegação (Conformidade W3C).
* **CSS3 Moderno:** Flexbox, CSS Grid, Variáveis CSS e Design Responsivo (Mobile-First).
* **JavaScript Vanilla:** Máscaras dinâmicas de entrada (CPF, Telefone, CEP) e integração com a API ViaCEP.
